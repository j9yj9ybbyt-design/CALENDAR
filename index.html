COME FUNZIONA

Informazioni

Un'applicazione web che non richiede un server per elaborare i documenti.

🔒 Privacy e sicurezza

I PDF vengono letti con PDF.js nel browser. Non sono inviati a GitHub né a server di elaborazione. I dati modificati vengono salvati nella memoria locale del dispositivo.

📱 Sempre disponibile online

Il sito può essere ospitato su GitHub Pages e aperto anche con il PC spento. La connessione Internet serve per caricare il sito e le librerie.

🔎 Verifica delle estrazioni

Il riconoscimento è basato su date, orari, parole chiave e coordinate del testo. Nei PDF scansionati serve OCR, non incluso nella versione web. Controlla sempre i campi segnalati.

↔ Trasferimento fra dispositivi

Salva una copia JSON dall'editor; usa “Importa backup JSON” nell'archivio dell'altro dispositivo. La sincronizzazione cloud con accesso riservato richiede una fase separata.
