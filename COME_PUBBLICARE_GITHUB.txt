VERSIONE 3 — SINCRONIZZAZIONE ACCOUNT

1) Crea un progetto Supabase (https://supabase.com).
2) Nel SQL Editor esegui il file supabase_setup.sql.
3) Inserisci URL del progetto e chiave publishable/anon nel file config.js.
4) Apri la repository CALENDAR in VS Code e sostituisci i file con quelli di questo pacchetto.
5) Ctrl+S -> Source Control -> Commit -> Sync Changes.
6) Accedi al sito da PC e telefono, usando il medesimo account Smart Calendar.

Per istruzioni dettagliate vedi README.md.
